O QUE MUDOU
- Câmera em 3ª pessoa MAIS PRÓXIMA e mais baixa (atrás das costas)
- Modelo mantido no solo e sombra de contato suave
- Movimentação acelerando e freando gradualmente
- Oscilação PROCEDURAL dos braços/pernas por shader (não é rigging real)
- Botão AÇÃO separado de FALAR (soco de treino)
- Botão EQUIP. para trocar entre punhos e tonfa
- Tonfa disponível após conversar com três cidadãos
- Arma de fogo fica bloqueada até uma futura missão de habilitação
- O progresso da Missão 01 salva com a mesma chave de v0.1

COMO ATUALIZAR NO GITHUB PELO CELULAR
1. Extraia o ZIP; NÃO envie o ZIP em vez dos arquivos.
2. Abra o repositório já existente: wesleyhulk-pixel/tio-urso-patrulha
3. Clique Add file > Upload files.
4. Selecione os CINCO arquivos extraídos.
5. Se o GitHub pedir para substituir arquivos existentes, confirme.
6. Faça o commit das alterações na branch main.
7. Acesse https://wesleyhulk-pixel.github.io/tio-urso-patrulha/?v=02

ATENÇÃO

  procedural é uma demonstração técnica, NÃO é caminhada com rig real.

- Não há socos contra cidadãos, dano ou arma funcional nessa versão.
- O carregamento usa Three.js por CDN, então precisa de internet.
- Se o navegador mostrar a versão anterior, atualize ou use a URL com ?v=02.
